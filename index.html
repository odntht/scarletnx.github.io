If a Switch is an ARM64-verse.
Then ScarletNX is FEX but in reverse.

ScarletNX is a static recompiler for Switch and Linux ARM programs.
Runs on FreeBSD, Windows, Linux and Solaris
Runs on x86_64, aarch64, powerpc64le, riscv64, sparc64 and DEC Alpha!
Supports only ARM64 for now! Stay tuned for updates.

If a Switch is an ARM64-verse.
Then ScarletNX is FEX but in reverse.

ScarletNX is a static recompiler for Switch and Linux ARM programs.
Runs on FreeBSD, Android, Windows, Linux, Solaris, NetBSD, OpenBSD, DragonFlyBSD, and AIX!
Runs on x86_64, aarch64, powerpc64le, riscv64, mips64, loongarch64, sparc64, and DEC Alpha!
Stay tuned on our Discord for updates.

We offer the following CI images:
Windows x86_64
Linux x86_64
Linux aarch64
Android (arm64, x86_64)

Windows: unzip ScarletNX-windows-x86_64.zip and run bin\scarletnx-gui.exe, the menu.
Linux: chmod +x ScarletNX-x86_64.AppImage (ScarletNX-aarch64.AppImage on ARM64), then run it: started bare, it opens the menu.
Android 5.0 and up: install ScarletNX-android.apk and allow it access to files; it works in /sdcard/ScarletNX.
Keys: encrypted dumps need your prod.keys, in ~/.switch/ (%USERPROFILE%\.switch\ on Windows) or in the data folder (~/.local/share/scarletnx, %APPDATA%\scarletnx). The menu's Setup device keys copies a dropped one to .switch; on Android it opens the file picker. Decrypted dumps and NROs need none.
Themes: see the ones ScarletNX has, or dress the menu with the theme builder.

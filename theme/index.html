ScarletNX theme builder

ScarletNX - the keys, in docs/GUI.md

This page needs JavaScript: it draws the preview and writes the file.

A theme dresses ScarletNX's menu (scarletnx-gui, the program the AppImage, the Windows zip and the Android app open): its colours, its head and footer, and how a run looks, as a console or as a loading screen. It is one file, theme.ini, in a folder named after the theme: themes/id/theme.ini, either

  • in the menu's data folder: ~/.local/share/scarletnx on Linux, %APPDATA%\scarletnx on Windows, /sdcard/ScarletNX on Android (a copy that keeps a games/ folder beside the AppImage or the zip's programs uses that folder instead), or
  • beside the menu's program: bin\themes in the Windows zip.

Then pick it with the menu's Theme item: each press goes to the next theme, the built-in Default and YoRHa first, then each folder of themes/. A folder named default or yorha replaces that built-in.

The file

theme.ini
the folder's name
[theme] base: choosing one starts the form over from that built-in, name and author kept
[theme] layout, for rEden's ErET, which reads the same file. loading: no base, YoRHa's menus, and [colors] become the loading screen's

The keys

Every key the menu reads, by section. A value the menu cannot take (too long, a colour that is not #RRGGBB) is written as it is and leaves the base's value; the note beside it says so, and the preview shows what the menu would.

theme.ini

The form writes this, and an edit here fills the form. Keys the menu does not read are kept, for the programs that do. The draft stays in this browser.
